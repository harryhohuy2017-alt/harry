# 3D Minecraft-like World Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first working 3D Minecraft-like world while preserving the existing 2D game as a fallback.

**Architecture:** Add a separate 3D entry point using Three.js/WebGL rather than replacing the existing Canvas game. The first milestone provides a first-person camera, voxel-style cube blocks, a small generated terrain, lighting, and basic rendering; later systems can build on its world/block interfaces.

**Tech Stack:** HTML, CSS, JavaScript, Three.js via CDN, WebGL.

## Global Constraints

- Preserve the existing 2D game as a fallback.
- Use keyboard arrows for movement preference.
- Use a first-person 3D camera.
- Keep the implementation lightweight enough for Vercel/browser deployment.
- Do not copy Minecraft assets, sounds, or proprietary code.

---

## Task 1: Add the 3D entry point

- [ ] Add a dedicated `3d.html` page that loads Three.js and the 3D game module.
- [ ] Add a clear link from the existing game to the 3D prototype.
- [ ] Verify the page loads without JavaScript errors.
- [ ] Commit: `feat: add 3d game entry point`

## Task 2: Build the voxel world

- [ ] Add `game3d.js` with a small deterministic block grid.
- [ ] Define Grass, Dirt, Stone, Sand, Wood, and Leaves block types.
- [ ] Create cube meshes from block coordinates.
- [ ] Generate a simple layered terrain with a few trees reserved for the later tree system.
- [ ] Verify blocks render as actual 3D cubes.
- [ ] Commit: `feat: add basic 3d voxel world`

## Task 3: Add first-person camera and movement

- [ ] Add first-person camera positioning and mouse-look when pointer lock is active.
- [ ] Map arrow keys to movement as requested.
- [ ] Add Shift sprinting.
- [ ] Prevent the player from falling through the ground.
- [ ] Verify walking and sprinting in the browser.
- [ ] Commit: `feat: add 3d player camera and movement`

## Task 4: Add basic 3D interaction foundation

- [ ] Add a center crosshair.
- [ ] Raycast from the camera to identify the targeted block.
- [ ] Highlight the targeted block.
- [ ] Implement left-click block removal.
- [ ] Implement right-click block placement.
- [ ] Verify removal/placement only affects the targeted voxel.
- [ ] Commit: `feat: add 3d block interaction`

## Task 5: Verify deployment compatibility

- [ ] Confirm all 3D files are committed to `main`.
- [ ] Check that the existing Vercel project serves the new 3D page.
- [ ] Open the deployed 3D page and verify rendering, camera, movement, and block interaction.
- [ ] Record any browser/WebGL compatibility issues before adding the next subsystem.
